# Folio

> **A personal portfolio website showcasing software engineering projects, UI/UX design work, technical skills, and professional experience.**

Folio is a responsive, multi-page personal portfolio website built as part of my AI Front-End Engineer internship at FlyRank AI.

The portfolio brings together my software engineering and UI/UX design work into one cohesive digital experience. It includes selected projects, project details, technical and design toolkits, education, leadership experience, professional information, and direct contact options.

The project is designed to grow over time as I build and complete more software projects and UI/UX case studies.

## Features

* **Personal Portfolio**
  A professional portfolio presenting my background, interests, skills, projects, and experience.

* **Responsive Homepage**
  A structured landing page introducing my professional identity and highlighting selected work.

* **Software Engineering Projects**
  Dedicated project showcase for software engineering work, including Hirely and Folio.

* **UI/UX Design Projects**
  Dedicated design section showcasing UI/UX projects including Shure and TheShoeU.

* **Project Details**
  Software projects include descriptions, ideas, implementation details, architecture, technologies, project status, repository links, and live versions.

* **Engineering Toolkit**
  A structured overview of my frontend, backend, programming language, and database technologies.

* **Design Toolkit**
  A dedicated overview of design tools and UI/UX capabilities.

* **About Page**
  Presents my educational background, interests, professional direction, and leadership experience.

* **Contact Page**
  Provides direct ways to connect through email, LinkedIn, GitHub, and other professional channels.

* **Project Repository Links**
  Visitors can directly access the source repositories of featured software projects.

* **Live Project Links**
  Featured projects can be opened directly through their deployed versions.

* **Design Project Previews**
  UI/UX projects are presented using visual project previews and descriptions.

* **Responsive Design**
  Designed to provide a consistent experience across desktop, tablet, and mobile screen sizes.

* **Scalable Portfolio Structure**
  The portfolio structure is designed so future projects and case studies can be added without rebuilding the entire website.

* **AI-Assisted Development**
  AI was used as a development and thinking partner throughout planning, implementation, debugging, UX refinement, and iteration.

## Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

You can verify the installations with:

    node --version
    npm --version
    git --version

### Installation

Clone the repository:

    git clone https://github.com/muhammadahsxn/folio.git

Navigate to the project directory:

    cd folio

Install dependencies:

    npm install

### Run the Development Server

Start the Next.js development server:

    npm run dev

Open:

    http://localhost:3000

### Production Build

To create a production build:

    npm run build

To run the production build locally:

    npm run start

### Lint

To run ESLint:

    npm run lint
